# Image generation prompts

Generated with the built-in imagegen tool, not the CLI fallback. Reference boards are design concepts; their sample transactions, people and product claims are not runtime app data.

## Shared prefix for the four boards

Use case: ui-mockup. Generate a high fidelity mobile app reference board for the existing URBAN BLADE grooming salon and care shopping app. One landscape board, five large straight-on 390x844 phone screens in a clean horizontal row, each labeled below, all fully visible. Premium soft ivory, warm sand, pale sage, deep forest green/charcoal controls. Typography exclusively Plus Jakarta Sans (original app font): clear geometric sans headlines, medium labels, no serif anywhere. Realistic frosted glass panels with visible background diffusion, delicate bright top rims, layered soft ambient and contact shadows, floating translucent bottom navigation, realistic amber and cream product photography. Inspired by luxury Lumee skincare and Scentora fragrance app references: editorial imagery, dense useful content, restrained consistent spacing, sophisticated depth. No neon, no purple, no gigantic empty regions, no heavy dark outlines. Native UI, not a web page. Indian rupee prices. These are design reference mockups, not actual transaction records.
