# UI/UX & Visual Polish Guidelines
> Extracted and adapted from liyupi/ai-guide (Vibe Coding Website Aesthetic Enhancement)

## 1. Eliminate "AI Taste" in Web Design
- **Color Palette**:
  - Avoid generic default blue-purple neon gradients.
  - Use curated, intentional brand palettes (e.g. Urban Blade's deep obsidian `#0b0f19`, champagne gold `#f59e0b` / `#d4af37`, and slate `#64748b`).
- **Typography**:
  - Use refined, modern typefaces (`Plus Jakarta Sans`, `Inter`, `Outfit`) with clear hierarchy and line-heights.
- **Iconography & Layout**:
  - Never spam emojis as substitutes for UI icons.
  - Use crisp SVG icons or standard icon glyphs.
  - Avoid identical "3-card" boilerplate layouts. Structure layouts based on user workflows (e.g., telemetry bars, data tables, detail drawers).

## 2. Micro-Interactions & Responsiveness
- Add subtle hover feedback (`transition: all 0.2s ease`, slight elevation or background shifts).
- Ensure mobile-responsive drawers, modals, and flexible flexbox/grid containers.
- Provide smooth loading skeletons or subtle spinners during background network operations.
